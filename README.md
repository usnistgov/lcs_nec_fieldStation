This repository provided code for NIST Low-Cost Sensor Air Quality Network field stations, used for the real-time measurement of CO2 and meteorological parameters in the Washington DC region. While NIST is no longer supporting this work, instructions for manufacturing and operating these boxes are made public so others may continue utilizing and innovating this solution. Please visit the page [wiki](https://github.com/usnistgov/lcs_nec_fieldStation/wiki) for further information and support.
